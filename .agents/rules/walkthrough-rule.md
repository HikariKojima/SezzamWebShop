# Always Provide a Walkthrough

Whenever completing a task, feature, or bugfix:

1. Always create or update `walkthrough.md` in the artifacts directory.
2. Ensure the walkthrough explains:
   - What was done and why.
   - How the feature works technically and functionally.

   - Verification checks and results.
3. Keep the explanations clear, concise, and structured so the user can easily understand how everything connects.
